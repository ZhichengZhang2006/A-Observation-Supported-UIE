## 4. 必须如实报告的三个问题

### 4.1 E0 基线本身是退化的，这削弱了整轮对比的意义

UIEB 上 E0（不加任何模块，只是继续训练）从 24.4604 掉到 23.8572，**掉 0.60 dB**。
这意味着「相对 E0 的增益」这个判据建立在一个不断下滑的基线上。

如果 E0 掉 0.6 dB，那么 E1 只掉 0.8 dB 时，"E1 比 E0 差 0.2 dB"这个结论
**部分反映的是 E0 掉得更少，而不是 E1 更差**。两个都在崩，比较的是谁崩得慢。

**这个混淆无法在现有数据内消除**，因为起点权重本身是在这个 val 上选出的最优
checkpoint，继续训练必然下滑。要得到干净的结论，需要从随机初始化重训 E0，
那是另一轮实验。

### 4.2 LSUI 的"持平"也可能是假的

LSUI 三条曲线在 30.94–31.02 之间震荡，波动幅度 0.05 dB。而
E1/E2 相对 E0 的效应只有 0.0003/0.0005 dB，**比这个震荡幅度小 100 倍**。

换句话说：**LSUI 上的"持平"结论，是在噪声中看不出差别**，
而不是"测出来确实相等"。以 CI 宽度 ±0.008 dB 计，任何小于 0.008 dB 的
真实效应都检测不到。

所以准确表述是：**LSUI 上没有任何可检测的效应**，不是"模块在 LSUI 上无效"。

### 4.3 e3_LSUI 未完成，LSUI 的对比缺一角

按因果链，LSUI 目前只有 E0/E1/E2 三档。E3（可学习门控）缺失，
所以「每增加一级复杂度是否更差」这个在 UIEB 上成立的模式，
**在 LSUI 上无法验证**。

## 6. 本阶段的净结论

**能确定的：**
1. 在 UIEB 上，四个配置全部无法超过起点，也无法超过 E0；复杂度越高越差。
2. 在 LSUI 上，三个配置全部无可检测的效应（效应量 < 0.001 dB）。
3. 两个数据集的行为差异**不是验证集大小造成的**（89 vs 428 张，波动都在 0.05 dB 量级）。
4. 训练本身健康：梯度通畅、两路都在学、损失正常下降。

**不能确定的：**
1. UIEB 上的失败有多少来自「E0 基线也在崩塌」这个混淆。
2. LSUI 上的"持平"是真实的无效，还是样本不足以分辨。
3. 如果换插入位置（1/8）或降低学习率，结论是否改变。
4. LSUI 的 E3 会是什么样。

**最有信息量的单一观察**：同一套模块，UIEB 退化 0.475 dB，LSUI 只退化 0.008 dB。
这个 60 倍的差异说明**模块本身不是问题所在，起点权重与数据集的适配程度才是**。
这直接指向一个未被检验的假设：UIEB 的起点可能已经过拟合到该 val，
而 LSUI 的起点还有余量。
